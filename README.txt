EADOR: ADRAGERON — GAME-STYLE REDESIGN

Что изменено по обратной связи заказчика:
- современный лендинг заменён на стилистику интерфейса самой Eador;
- бордово-тёмная игровая фактура вместо чистого современного UI;
- пергаментные панели, золотые рамки, декоративные игровые кнопки;
- круговые медальоны и орнаментальные элементы;
- реальные логотип и скриншоты игры встроены в дизайн;
- сохранены разделы из ТЗ: скачать игру, об игре, онлайн, новости, changelog, сообщество;
- адаптивная версия для телефона;
- рабочая кнопка «наверх»;
- раскрывающийся changelog;
- кнопка скачивания показывает сообщение, пока реальная ссылка не предоставлена.

Нужно получить от заказчика для финала:
1. Реальную ссылку на сборку игры.
2. Актуальный номер версии и дату.
3. Реальный changelog.
4. Ссылку на VK-группу.
5. При необходимости — дополнительные скриншоты/макеты из Figma.
